## Overview
This **Fish Game with Particles** is an interactive canvas-based game where you control a fish that swims around the screen and pops floating bubbles. The game also includes a unique "bubble text" effect that reacts to the player’s fish.

It is based on the “Fish game with particles” by [Frank’s Laboratory](https://www.youtube.com/channel/UCEqc149iR-ALYkGM6TG-7vQ) (2020), and has been modified by MASerrano to include new features and styling.

## How to Play
1. **Move your mouse** over the canvas area to direct the fish.  
2. The fish will move toward your mouse position, and the angle of the fish changes accordingly.  
3. **Pop bubbles** by colliding with them. Each pop increases your score.  
4. Watch the **bubble text** spelled out in bubbles, reacting to your fish’s movement.  
5. The game runs continuously, so aim for the highest score you can!

## Installation & Usage
1. **Clone or Download** this repository.  
2. Open the `index.html` file in your browser to run the game locally.  
3. Alternatively, visit the live link on [GitHub Pages](https://serranolab.github.io/online/) to play the game online.  

### File Structure
- **index.html**  
  Contains the main HTML structure and references to the necessary CSS and JS files.
- **style-glass.css**  
  Provides the styling for the game container, background gradient, bubble text effects, and animated header.
- **script.js**  
  Holds the core JavaScript logic, including player movement, bubble spawning & popping mechanics, and the animation loop.
